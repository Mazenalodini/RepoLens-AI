# Project Context

RepoLens AI is a GitHub Repository Intelligence platform.

The primary user action is:

```text
Provide GitHub Repository URL
```

The product then:

```text
Acquire
→ Discover
→ Analyze
→ Normalize Findings
→ AI Review
→ Report
```

Primary architectural principle:

> Evidence First, AI Assisted.

The MVP is intentionally a Modular Monolith.

Development is Windows-first.

AI agents are development assistants operating under Human-in-the-Loop control.
