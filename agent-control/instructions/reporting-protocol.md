# Reporting Protocol

After each task, the Agent must provide a concise engineering handoff.

Required sections:

### STATUS

Completed / Partially Completed / Blocked

### IMPLEMENTATION

What was implemented and why.

### FILES CHANGED

Created / Modified / Deleted.

### TESTS

Exact test commands executed and observed result.

### REVIEW

Important observations from the final diff.

### LIMITATIONS

Known limitations or unresolved issues.

### MANUAL COMMANDS

Commands the user should execute themselves.

### GIT CHECKPOINT

Suggested `git status`, `git diff`, `git add`, `git commit`, and `git push` actions when appropriate.

### SCREENSHOT CHECKPOINT

Identify the most useful screenshot evidence.

### NEXT TASK

One recommended next bounded task.

Never claim a command was executed if it was only suggested.
